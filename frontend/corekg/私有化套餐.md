# 套餐和模块配置文档

## 套餐列表

| 套餐名称 | 套餐 Key | 说明                             |
| -------- | -------- | -------------------------------- |
| 智能体版 | `agent`  | 基础版本，不包含知识图谱相关功能 |
| 全能版   | `all`    | 完整版本，包含所有功能           |

## 模块列表

| 模块名称 | 模块 Key |
| -------- | -------- |
| 问答     | `chat`   |
| 知识库   | `forest` |
| 智能体   | `agent`  |
| 图谱     | `graph`  |

## 套餐包含模块关系

### 智能体版 (Key: `agent`)

- ✅ 问答 (`chat`)
- ✅ 知识库 (`forest`)
- ✅ 智能体 (`agent`)
- ❌ 图谱 (`graph`)

### 全能版 (Key: `all`)

- ✅ 问答 (`chat`)
- ✅ 知识库 (`forest`)
- ✅ 智能体 (`agent`)
- ✅ 图谱 (`graph`)

## 套餐 JSON 配置

```json
{
  "packages": [
    {
      "key": "agent",
      "name": "智能体版",
      "modules": ["chat", "forest", "agent"]
    },
    {
      "key": "all",
      "name": "全能版",
      "modules": ["chat", "forest", "agent", "graph"]
    }
  ]
}
```

## TypeScript 类型定义

```typescript
/**
 * 私有化套餐的key
 */
type CustomPackage = 'agent' | 'all'

/**
 * 私有化模块的key
 */
type CustomModule = 'chat' | 'forest' | 'agent' | 'graph'
```
